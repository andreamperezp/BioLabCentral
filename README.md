# BioLab Central

Sitio web de demostración para un laboratorio clínico, con diseño responsive (móvil, tablet y escritorio).

## Secciones

- Portada con llamada a la acción y cifras destacadas
- Servicios (hematología, biología molecular, microbiología, química clínica, toma a domicilio, chequeos empresariales)
- Cómo funciona (3 pasos)
- Portal de resultados (demo)
- Sedes con filtro por zona
- Preguntas frecuentes
- Formulario para agendar cita (demo)

## Uso

Es HTML, CSS y JavaScript sin dependencias. Abre `index.html` en el navegador o sírvelo localmente:

```bash
npx http-server . -p 5173
```
